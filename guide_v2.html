Born2beRoot - Guía Completa de Estudio

1. Introducción y Conceptos Básicos

Esta sección resume los fundamentos teóricos necesarios para comprender qué se está configurando y por qué es obligatorio en el proyecto Born2beRoot.

ISO

Qué es: Archivo único que contiene una copia exacta y completa de un soporte óptico o sistema de archivos (estructura interna, metadatos y ficheros ocultos).

Para qué sirve: Permite instalar sistemas operativos, realizar copias de seguridad de discos completos o distribuir software de forma fiable.

Máquina Virtual e Hipervisor

Qué es: Entorno aislado que emula un hardware independiente (CPU, RAM, disco) utilizando los recursos físicos del equipo anfitrión.

💡 Analogía: La máquina física es un edificio y VirtualBox es un arquitecto que crea mini-apartamentos independientes (VMs) dentro del edificio.

LVM (Logical Volume Manager)

Qué is: Método flexible de gestión de almacenamiento en disco.

Por qué se usa: A diferencia de las particiones fijas tradicionales, LVM permite redimensionar, ampliar o reducir volúmenes lógicos fácilmente en caliente, como si fuesen piezas desmontables.

Cifrado de Disco (LUKS)

Qué es: Encriptación de todos los datos del disco mediante clave. Si el disco duro físico es extraído o robado, la información resulta ilegible sin la contraseña de descifrado al arrancar.

SSH, OpenSSH y Port Forwarding

SSH: Protocolo de acceso remoto seguro a un servidor por línea de comandos mediante canal cifrado.

Port Forwarding: Permite conectar el puerto local de la máquina anfitriona (ej. 4243) con el puerto del servidor virtualizado (4242), ya que la VM opera en una red privada aislada.

AppArmor vs SELinux

Módulos de seguridad del Kernel (MAC) que limitan las acciones permitidas a cada programa aunque el usuario tenga permisos elevados.

  • AppArmor (Debian): Trabaja con perfiles basados en rutas absolutas de archivos (ej. Firefox solo accede a /home/user/Downloads).
  • SELinux (Rocky Linux): Trabaja con etiquetas de seguridad asignadas a cada archivo, proceso y usuario mediante reglas estrictas de interacción.

PAM y Libpam-pwquality

PAM: Sistema modular en Linux para gestionar la autenticación (inicio de sesión, cambio de claves, etc.).

Libpam-pwquality: Módulo de seguridad para PAM que comprueba y exige que las contraseñas cumplan requisitos estrictos de complejidad.

TTY y Scripting

TTY (TeleTYpewriter): Terminal de texto puro sin entorno gráfico (fondo negro y texto blanco).

Script en Bash: Archivo ejecutable de texto que secuencia comandos automáticos de arriba a abajo.

2. Creación de la Máquina Virtual

Pasos exactos en Oracle VirtualBox:

  1. Pulsar Nueva (New).
  2. Name: Born2beRoot
  3. Folder: Seleccionar /sgoinfre (directorio temporal para evitar saturar el espacio de usuario).
  4. ISO Image: Seleccionar la imagen descargada de Debian (ej. debian-13.4.0-amd64-netinst.iso).
  5. Marcar la casilla Skip unattended installation y pulsar Next.
  6. Hardware: Asignar 1024 MB RAM (1 GB) y 1 vCPU. Pulsar Next.
  7. Virtual Hard disk: Crear un disco virtual de 20 GB. Pulsar Next y finalizar con Finish.

3. Instalación de Debian Paso a Paso

  1. Iniciar la VM y seleccionar la opción Install (instalación en modo texto).
  2. Seleccionar idioma, ubicación y distribución de teclado.
  3. Hostname: Indicar valmoral42.
  4. Domain name: Dejar en blanco y continuar.
  5. Contraseña de root: Configurar Urduliz42.2026.
  6. Usuario estándar: Crear usuario valmoral con contraseña Urduliz42.2026.
  7. Seleccionar zona horaria (ej. Península).
  8. Selección de programas (Software selection): Desmarcar el entorno de escritorio gráfico y servidor web. Marcar **únicamente**:
    • SSH server
    • standard system utilities

4. Particionado de Disco y LVM Cifrado

  1. En el menú de particionado, elegir: Guiado - utilizar todo el disco y configurar LVM cifrado.
  2. Elegir el disco predeterminado de 20 GB.
  3. Seleccionar el esquema: Separar la partición /home.
  4. Aceptar guardar los cambios en el disco cuando lo solicite.
  5. Introducir la contraseña de cifrado de disco dos veces: Urduliz42.2026.
  6. Indicar el tamaño del volumen asignado (por defecto tomar el máximo disponible, aprox. 20.5 GB).
  7. Finalizar el particionado y escribir los cambios en el disco seleccionando Sí.
  8. Instalación de GRUB: Seleccionar Sí e instalar el cargador en la unidad principal /dev/sda.

5. Sudo y Gestión de Usuarios

Acceder como root (su -) e instalar sudo:

apt update && apt install sudo -y

Añadir el usuario a los grupos obligatorios:

addgroup user42
adduser valmoral user42
adduser valmoral sudo

Para comprobar que pertenece a los grupos correctamente: getent group user42 y getent group sudo.

Configuración estricta de Sudo

Crear el fichero de configuración de sudo:

touch /etc/sudoers.d/sudo-config
mkdir -p /var/log/sudo
nano /etc/sudoers.d/sudo-config

Añadir las siguientes directivas obligatorias:

Defaults passwd_tries=3
Defaults badpass_message="Invalid password, try again"
Defaults logfile="/var/log/sudo/sudo_config"
Defaults log_input, log_output
Defaults iolog_dir="/var/log/sudo"
Defaults requiretty
Defaults secure_path="/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin:/snap/bin"

6. Configuración de SSH y Cortafuegos UFW

Configurar SSH

Editar el fichero de configuración del servidor SSH:

nano /etc/ssh/sshd_config
  • Descomentar y modificar el puerto: Port 4242
  • Descomentar y denegar acceso root: PermitRootLogin no

Editar también el cliente SSH en /etc/ssh/ssh_config descomentando Port 4242.

Reiniciar el servicio SSH: sudo service ssh restart y verificar estado con sudo service ssh status.

Configurar Cortafuegos (UFW)

sudo apt install ufw -y
sudo ufw enable
sudo ufw allow 4242
sudo ufw status numbered

Port Forwarding en VirtualBox

Con la VM apagada o desde Ajustes:

  1. Ir a Red -> Avanzado -> Reenvío de puertos (Port Forwarding).
  2. Añadir regla:
    • Host Port: 4243 (o puerto libre en el anfitrión)
    • Guest Port: 4242

Probar conexión desde la terminal del ordenador anfitrión:

ssh valmoral@localhost -p 4243

7. Política de Contraseñas Fuertes (PAM)

Configuración de Caducidad (`/etc/login.defs`)

nano /etc/login.defs

Modificar los parámetros existentes:

PASS_MAX_DAYS   30
PASS_MIN_DAYS   2
PASS_WARN_AGE   7

Configuración de Complejidad con PAM

sudo apt install libpam-pwquality -y
sudo nano /etc/pam.d/common-password

Añadir a la línea que contiene pam_pwquality.so las siguientes reglas:

minlen=10 ucredit=-1 lcredit=-1 dcredit=-1 maxrepeat=3 reject_username difok=7
📌 Explicación de parámetros:
  • minlen=10: Mínimo 10 caracteres.
  • ucredit=-1: Mínimo 1 mayúscula.
  • lcredit=-1: Mínimo 1 minúscula.
  • dcredit=-1: Mínimo 1 dígito.
  • maxrepeat=3: Máximo 3 caracteres idénticos consecutivos.
  • reject_username: No puede contener el nombre del usuario.
  • difok=7: Mínimo 7 caracteres distintos a la clave anterior.

Aplicar la nueva caducidad a los usuarios ya creados:

sudo chage -m 2 -M 30 valmoral
sudo chage -m 2 -M 30 root
sudo chage -l valmoral

8. Script monitoring.sh Explicado Comando a Comando

Crear el fichero ejecutable en /home/valmoral/monitoring.sh:

#!/bin/bash

# Arquitectura y versión del Kernel
arch=$(uname -a)

# Número de procesadores físicos
pcpu=$(grep "physical id" /proc/cpuinfo | sort -u | wc -l)

# Número de procesadores virtuales (vCPU)
vcpu=$(grep "^processor" /proc/cpuinfo | wc -l)

# Memoria RAM (Total, Usada y Porcentaje)
fram=$(free -m | awk '$1 == "Mem:" {print $2}')
uram=$(free -m | awk '$1 == "Mem:" {print $3}')
pram=$(free -m | awk '$1 == "Mem:" {printf("%.2f"), $3/$2*100}')

# Memoria de Disco (Storage)
fdisk=$(df -m | grep "/dev/" | grep -v "/boot" | awk '{f += $2} END {print f}')
udisk=$(df -m | grep "/dev/" | grep -v "/boot" | awk '{u += $3} END {print u}')
pdisk=$(df -m | grep "/dev/" | grep -v "/boot" | awk '{u += $3; f += $2} END {printf("%d"), u/f*100}')

# Carga de la CPU (%)
cpul=$(vmstat 1 2 | tail -1 | awk '{printf("%.1f"), 100 - $15}')

# Fecha y hora del último reinicio
lb=$(who -b | awk '{print $3" "$4}')

# Uso de LVM activo o no
lvmu=$(if [$(lsblk | grep "lvm" | wc -l) -gt 0 ]; then echo yes; else echo no; fi)

# Conexiones TCP activas ESTABLISHED
tcpc=$(ss -ta | grep ESTAB | wc -l)

# Número de usuarios logueados
ulog=$(users | wc -w)

# Dirección IPv4 y MAC
ip=$(hostname -I)
mac=$(ip link | grep "link/ether" | awk '{print $2}')

# Número de comandos ejecutados con sudo
cmnd=$(journalctl _COMM=sudo | grep COMMAND | wc -l)

# Imprimir información en todos los terminales
wall "  #Architecture: $arch
        #Physical CPU: $pcpu
        #vCPU: $vcpu
        #Memory Usage: $uram/${fram}MB ($pram%)
        #Disk Usage: $udisk/${fdisk}Mb ($pdisk%)
        #CPU load: $cpul%
        #Last boot: $lb
        #LVM use: $lvmu
        #Connections TCP: $tcpc ESTABLISHED
        #User log: $ulog
        #Network: IP $ip ($mac)
        #Sudo: $cmnd cmd"

Asignar permisos de ejecución:

chmod +x /home/valmoral/monitoring.sh

9. Automatización con Crontab

Cron es un administrador de tareas en segundo plano. Para ejecutar el script cada 10 minutos desde la cuenta root:

sudo crontab -u root -e

Seleccionar el editor /bin/nano y añadir al final del fichero:

*/10 * * * * /home/valmoral/monitoring.sh

10. Generación de la Huella Digital (signature.txt)

Obtener el hash SHA1 del disco virtual .vdi desde la terminal de la máquina anfitriona (host):

Sistema Anfitrión Comando a Ejecutar
Linux / macOS shasum Born2beRoot.vdi > signature.txt
Windows (PowerShell) certUtil -hashfile Born2beRoot.vdi SHA1 > signature.txt

El archivo signature.txt es el único entregable en el repositorio de Git junto con el README.md.

11. Guía de Evaluación y Preguntas de Defensa

Preguntas Teóricas Habituales

  • ¿Por qué elegiste Debian sobre Rocky Linux? Debian utiliza paquetes .deb con la herramienta apt, es sumamente estable y óptimo para servidores pequeños sin componentes innecesarios.
  • Diferencia entre apt y aptitude: apt es la herramienta estándar de línea de comandos. aptitude incluye una interfaz basada en texto (TUI) y resuelve dependencias complejas de forma más avanzada.
  • ¿Qué es LVM y qué ventajas ofrece? Permite gestionar el almacenamiento como volúmenes lógicos dinámicos, facilitando redimensionar particiones sin formatear el disco.

Prácticas que te pedirán en directo durante la evaluación

  1. Cambiar el Hostname: 
    sudo hostnamectl set-hostname nuevoLogin42
    Editar también /etc/hosts sustituyendo el antiguo hostname por el nuevo.
  2. Crear un usuario nuevo y meterlo en el grupo user42: 
    sudo adduser nuevoUsuario
sudo addgroup user42
sudo adduser nuevoUsuario user42
getent group user42
  3. Comprobar la política de contraseñas: Crear un usuario con clave débil para demostrar que el sistema la rechaza.
  4. Verificar UFW y SSH: Mostrar las reglas activas con sudo ufw status y conectar por SSH desde el equipo anfitrión.
  5. Detener la ejecución del script temporalmente: Editar el crontab (sudo crontab -e) y comentar la línea poniendo un # al inicio.
