1. Conceptos Teóricos Clave

  • ISO: Archivo único que contiene una copia exacta y completa de una estructura de archivos/sistema operativo. Servidor para instalar SOs o montar discos virtuales.
  • LVM (Logical Volume Manager): Gestión flexible de discos que permite redimensionar, ampliar o reducir particiones fácilmente sin reiniciar.
  • Cifrado (LUKS): Codificación completa del disco mediante contraseña para proteger los datos frente a accesos no autorizados.
  • SSH & OpenSSH: Protocolo y software para acceso remoto seguro a la línea de comandos mediante canal cifrado.
  • AppArmor / SELinux: Módulos de seguridad del Kernel (MAC) que restringen las acciones de las aplicaciones mediante perfiles o etiquetas.
  • PAM & Libpam-pwquality: Sistema de autenticación de Linux y módulo para imponer políticas estrictas de complejidad de contraseñas.
  • TTY (TeleTYpewriter): Terminal de texto puro sin interfaz gráfica.

6. SSH y Cortafuegos (UFW)

Editar /etc/ssh/sshd_config:

Port 4242
PermitRootLogin no

Configurar UFW:

sudo apt install ufw
sudo ufw enable
sudo ufw allow 4242
sudo ufw status

7. Políticas de Contraseña Fuerte

Editar /etc/login.defs:

PASS_MAX_DAYS   30
PASS_MIN_DAYS   2
PASS_WARN_AGE   7

Editar /etc/pam.d/common-password añadiendo a la línea de pam_pwquality.so:

minlen=10 ucredit=-1 lcredit=-1 dcredit=-1 maxrepeat=3 reject_username difok=7

8. Script monitoring.sh

#!/bin/bash
arch=$(uname -a)
pcpu=$(grep "physical id" /proc/cpuinfo | sort -u | wc -l)
vcpu=$(grep "^processor" /proc/cpuinfo | wc -l)
fram=$(free -m | awk '$1 == "Mem:" {print $2}')
uram=$(free -m | awk '$1 == "Mem:" {print $3}')
pram=$(free -m | awk '$1 == "Mem:" {printf("%.2f"), $3/$2*100}')
fdisk=$(df -m | grep "/dev/" | grep -v "/boot" | awk '{f += $2} END {print f}')
udisk=$(df -m | grep "/dev/" | grep -v "/boot" | awk '{u += $3} END {print u}')
pdisk=$(df -m | grep "/dev/" | grep -v "/boot" | awk '{u += $3; f += $2} END {printf("%d"), u/f*100}')
cpul=$(vmstat 1 2 | tail -1 | awk '{printf("%.1f"), 100 - $15}')
lb=$(who -b | awk '{print $3" "$4}')
lvmu=$(if [$(lsblk | grep "lvm" | wc -l) -gt 0 ]; then echo yes; else echo no; fi)
tcpc=$(ss -ta | grep ESTAB | wc -l)
ulog=$(users | wc -w)
ip=$(hostname -I)
mac=$(ip link | grep "link/ether" | awk '{print $2}')
cmnd=$(journalctl _COMM=sudo | grep COMMAND | wc -l)

wall "  #Architecture: $arch
        #Physical CPU: $pcpu
        #vCPU: $vcpu
        #Memory Usage: $uram/${fram}MB ($pram%)
        #Disk Usage: $udisk/${fdisk}Mb ($pdisk%)
        #CPU load: $cpul%
        #Last boot: $lb
        #LVM use: $lvmu
        #Connections TCP: $tcpc ESTABLISHED
        #User log: $ulog
        #Network: IP $ip ($mac)
        #Sudo: $cmnd cmd"

10. Firma del Disco Virtual (signature.txt)

Obtener el SHA1 del archivo .vdi desde la máquina anfitriona:

# Linux / Mac
shasum Born2beRoot.vdi > signature.txt

# Windows PowerShell
certUtil -hashfile Born2beRoot.vdi SHA1 > signature.txt

11. Preguntas Frecuentes en la Evaluación

  • Debian vs Rocky: Debian usa paquetes .deb con gestor apt; Rocky usa .rpm con dnf/yum. Debian es más estable e ideal para servidores generales.
  • Apt vs Aptitude: apt es la herramienta de línea de comandos estándar. aptitude incluye una interfaz gráfica basada en texto (TUI) y resuelve dependencias complejas con más opciones.
  • AppArmor vs SELinux: AppArmor usa rutas de archivos para definir perfiles. SELinux asigna etiquetas de seguridad a procesos y objetos.
